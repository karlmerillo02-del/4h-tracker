## Top 3 highest-risk findings before user testing

1. **Verify the safety policy source:** The app uses cutoffs reported in the linked DepEd news release, but the signed DepEd Memorandum No. 64, s. 2026 is not in this project. Confirm every action and cutoff against the memo before use for school decisions.
2. **Verify heat-index calculations:** The app implements the NOAA/NWS formula and domain guard, but it still needs automated comparison tests against published NOAA/NWS test cases and decision-boundary cases.
3. **Verify safe access for all users:** The interface remains text-led and does not offer voice input; remote speech recognition would conflict with the privacy promise. Test icon-led alternatives with target users, and keep voice input disabled unless offline processing is verified.

Voice input and photographic UI assets are intentionally not included: remote speech services would conflict with the no-transmission promise, and offline-available photos need a suitable licensed asset source. Neither limitation is represented as passing.
